# Ready-to-use prompts

These prompts are optional. Natural language works too.

## 1. Install from GitHub

```text
Open this GitHub repository and install it as an Agent Skill.
Use the entire repository as the Skill package, not only SKILL.md.
Read SKILL.md and START-HERE.md, run its self-test, and report PASS / BLOCKED / NOT_TESTED honestly.
After installation, do not start inventing a design style for me; wait for my actual task or references.
```

## 2. Build my long-term Design System

```text
Use Design System Creator to build a long-term personal Design System for me.
First verify that you can actually see image content. I will send references in multiple messages.
While I am sending them, only collect and register them; do not analyze yet.
When I say “上传完成”, validate what you received. Only after I say “开始分析” may you analyze them.
Separate OBSERVED, INFERRED and CONFIRMED decisions, bind important conclusions to evidence, and interview me only where uncertainty is material.
The final system should cover Web, DOCX, PPTX, XLSX, PDF and Charts, with anti-style rules, tokens, profiles, versioning, QA and a portable Runtime Skill.
```

## 3. Make something without a full onboarding

```text
Use Design System Creator for this task, but do not force a full Design System onboarding.
Create a temporary design context for this deliverable, infer only what is necessary, and keep temporary art direction separate from any long-term Design Kernel.
Produce the real artifact using the best renderer available in this host and run medium-specific QA before delivery.
```

## 4. Use my existing Design Kernel

```text
Use my existing Design Kernel as the identity layer for this task.
Do not reinterpret or overwrite confirmed long-term preferences.
Create a task-specific Creative Direction, resolve it with the active profile and medium constraints, then produce the artifact.
If this task needs a one-off visual departure, put it in Temporary Art Direction instead of mutating the Kernel.
```

## 5. Audit a Design System or artifact

```text
Audit this Design System / artifact with Design System Creator.
Check Identity consistency, Creative Direction quality, medium suitability and technical quality separately.
Show concrete violations and evidence instead of giving a vague aesthetic score.
Do not rewrite confirmed rules unless I explicitly approve a Design Kernel change.
```
