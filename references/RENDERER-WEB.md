# Web Renderer

Web is an interactive, responsive experience—not a stack of generic cards.

Start from Content Semantics + Resolved Design Context. Establish a content-specific visual subject/metaphor and 3+ visual signature rules. Use semantic HTML, responsive layout, keyboard/accessibility basics, reduced-motion fallback and performance-aware assets.

Motion/3D only exists when it clarifies sequence, state, relationship or atmosphere appropriate to the content. Avoid generic glass cards, unexplained gradients, fake HUD data, decorative rotating spheres and identical fade-ins.

When direction is uncertain, use `VISUAL-PITCH.md`. `scripts/build_visual_pitch.py` is a workflow smoke test, not a final template. Real projects should use content-specific production.

QA should include real browser screenshots at desktop and mobile when the host permits, plus interaction/overflow/link checks.
