# Design Kernel

长期身份层，不是模板。

证据状态：OBSERVED（直接观察）、INFERRED（推断）、CONFIRMED（用户或正式规范明确确认）。高置信度 INFERRED 不等于 CONFIRMED。

Kernel 包含 philosophy、principles、anti_style、personality、color/typography/spacing/grid/radius/border/shadow、imagery、motion、charts、accessibility、profiles、medium_rules、provenance、decisions、version。

Preference Interview 不固定十问；优先追问低置信度、高影响、冲突项。区分“喜欢极简”与“讨厌混乱”等看似相同的表述。

Tokens 三层：Foundation → Semantic → Medium/Component。Core 保存稳定身份；Profile 只覆盖必要差异。每个维度记录 maturity/completeness，允许系统先达到可用状态。
