# Resolved Design Context

所有 Renderer 的共享中间表示。合并：Kernel Core → Active Profile → Current Task/Content → Temporary Art Direction → Medium Constraints → Explicit Overrides。

输出：resolved tokens、typography/layout/imagery/motion、active anti-style、content hierarchy、creative direction、medium constraints、provenance summary、conflicts/resolution、QA checklist。Renderer 不得无记录地重新定义长期身份。
