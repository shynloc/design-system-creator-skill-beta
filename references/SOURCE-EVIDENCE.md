# Source & Evidence Discipline

Every durable design conclusion should be explainable.

Recommended fact record:
```json
{
  "id": "typography.serif-editorial",
  "value": true,
  "status": "INFERRED",
  "confidence": 0.82,
  "evidence": ["R03:headline", "R07:cover", "conversation:D12"],
  "note": "Repeated preference; awaiting durable confirmation."
}
```

Evidence may come from user-provided visual references, existing design systems, explicit preference statements, correction signals, or confirmed decisions. Do not cite a file merely because its filename suggests a style.

Negative/correction evidence is first-class: “不要这样” can be stronger than passive exposure to a style.

When evidence conflicts, preserve the conflict and ask for/derive a task-local resolution; do not silently overwrite provenance.
