# PPTX Renderer

PPTX is a paced presentation medium. Do not enlarge a document or repeat one card layout.

## Layout grammar
Support at minimum: Cover, Section, Statement, Evidence, Data, Comparison, Process, Timeline, Quote, Image-led, Conclusion/Action.

Each slide has one dominant communication job. Define title/content/evidence/footer zones but vary composition by message. Use speaker/viewing distance appropriate type sizes; preserve editability.

## Design mapping
Kernel defines identity; Creative Direction defines this deck's narrative and visual metaphor. Temporary Direction may legitimately change density, contrast or image treatment without mutating the Kernel.

## Host execution
Use native presentation/PPTX tooling when available. If unavailable, do not fabricate a `.pptx`; provide storyboard + slide specs and mark generation BLOCKED.

## QA
Render slides to images/PDF when possible. Check hierarchy, overflow, alignment, repeated layouts, contrast, chart legibility, image resolution, safe margins and story rhythm. Verify at least Cover + dense slide + data/diagram slide + ending.
